# 📘 Today I Learned

### 1. 오늘 배운 내용
- Spring Boot 프로젝트를 생성하고, 기존 Java 프로젝트 코드를 Spring 방식으로 전환하는 실습을 진행했다.
@Configuration과 @Bean을 사용한 수동 Bean 등록 방식을 실습했다.
@Service, @Repository 어노테이션을 사용하여 자동 Bean 등록과 의존성 주입을 실습했다.
브라우저에서 요청을 보내고 응답을 확인했다.
@SpringBootApplication이 있는 패키지를 기준으로 하위 패키지들을 스캔하기 때문에 패키지 구조가 중요하다는 것을 알게 되었다.

### 2. 핵심 정리 (내 언어로)
- 이전에는 new 키워드로 객체를 직접 생성하고 연결했지만, Spring에서는 스프링 컨테이너가 객체를 대신 생성하고 관리해준다.
수동 주입에서는 @Configuration과 @Bean을 등록했고, 자동 주입에서는 @Service, @Repository 같은 어노테이션만으로 Bean 등록과 의존성 주입이 가능했다.
@RestController는 HTTP 요청을 처리하는 클래스이고, @GetMapping("/hello")을 사용하면 특정 URL 요청에 대한 응답을 쉽게 만들 수 있다.

### 4. 느낀 점
- Spring에서는 어노테이션만으로 자동 관리가 가능해서 훨씬 편리하다고 느꼈다.
자동 주입 방식은 개발자가 직접 관리하지 않아도 스프링이 알아서 연결해준다는 점이 인상적이었다.
패키지 구조처럼 작은 설정 하나로 오류가 발생할 수 있다는 점을 경험했다.
